## What's Inside

- [Kerem Aslan/](Kerem%20Aslan/) contains a Vehicle Routing Problem workshop. It includes a Gradio app, solver code, and sample datasets for experimenting with routing and time windows.
- [Christopher J. Garcia/](Christopher%20J.%20Garcia/) contains a rental car revenue management notebook that walks through optimization scenarios step by step.

## How To Use It

Open the folder for the session you want to explore and start from the main file inside it. The code is meant for learning, so the best way to use it is to run the examples, change the inputs, and see how the solutions change.
